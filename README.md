# OPTCG Scraping Project

## 📜 OPTCG Scraping Tool
A dedicated web scraping project for collecting and processing data to support another project related to the One Piece Trading Card Game (OPTCG).

## 🔍 Key Features:
Automated data extraction (cards, sets, metadata, etc.) from One Piece Card Game official website.  
Data cleaning and structuring for seamless integration into downstream projects.  
Designed for use in OPTCG-related applications, analytics, or community tools.

## 🛠️ Tech Stack:
- Python
- Selenium

## 📂 Project Structure:
`/scrapers`: Scraping scripts organized by source.  
`/data`: Raw and processed data outputs.    

## 📌 Purpose:
This repository aims to streamline data collection for OPTCG, enabling myself, developers and enthusiasts to build tools, dashboards, or analyses without manual data entry.

## ⚠️ Important Notes:
Always comply with the terms of service of the scraped websites.  
Data is provided as-is and may require periodic updates.
